# Mi primer proyecto Android

App de bienvenida en Android (Java) que:

1. **Soporta 4 idiomas**: Español (por defecto), Inglés, Francés y Alemán (`values`, `values-en`, `values-fr`, `values-de`).
2. **Usa un fondo nine-patch** (`res/drawable-xxhdpi/fondo.9.png`) redimensionable sin deformar al robot Android.
3. **Soporta múltiples pantallas y orientaciones** con `ConstraintLayout` + guías en porcentaje, `layout-land/` y `dimens.xml` por ancho (`sw600dp`, `sw720dp`).

## Cómo abrirlo
1. Android Studio → *File > Open* → seleccionar esta carpeta.
2. Esperar la sincronización de Gradle y ejecutar (▶) en un emulador o dispositivo.
